# Hindi translation: review sheet

Every piece of text in the PISA-style units, in English and in the Hindi draft, side by side. The Hindi was written for Hindi-medium schools in Uttar Pradesh and has not yet been checked by a Hindi-medium maths teacher. If a line sounds wrong, stiff or too bookish for a Class 8 child, write a better version in the last column and send it back (an issue on GitHub, or the email in the README). Numbers come from one example unit per template; in real units they change, the words do not.

Answer letters A to D and the answer-sheet codes (T, F, full, partial, none, RF, PK, CF, INT) stay in English on purpose, so one answer sheet works for a class that uses both languages. Amounts are written ₹270 in Hindi and Rs 270 in English, and times as सुबह 7:30 बजे, so rows that differ only in that are left out.

This file is made by `confusion_mapper.pisa.format_translation_review()`. The words on the web page itself (buttons, headings) are in the `I18N` block of worksheets/index.html.
